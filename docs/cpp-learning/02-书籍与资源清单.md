## 二、必收藏在线资源（本地的书替代不了的）

### 系统学习

- **[learncpp.com](https://www.learcpp.com/)** ⭐⭐ — 全世界最好的免费 C++ 教程：从零到 STL，每章带 quiz，持续更新到 C++23/26。**基础重建阶段的主线教材**（内容有版权未开源，在线阅读）
- [cppreference.com](https://cppreference.com/)（[中文版](https://zh.cppreference.com/)）— 标准库与语言行为的权威参考（相当于 Rust 的 std 文档），有[官方离线包](https://en.cppreference.com/w/Cppreference:Archives)可下载
- [hackingcpp.com](https://hackingcpp.com/)** ⭐ — 图解现代 C++ 教程 + 大量速查图（cheatsheets），可视化质量极高，适合快速恢复记忆
- [C++ FAQ (isocpp.org)](https://isocpp.org/faq) — 经典 FAQ，很多"为什么"的答案在这里

### 视频

- **[The Cherno - C++ 系列](https://www.youtube.com/playlist?list=PLlrATfBNZ98dudnM48y2g3Ysuh24lZthP)**（YouTube，免费 100+ 集）— 讲解极其清晰，前 EA 引擎开发者，复习期当"陪读"
- [C++ Weekly（Jason Turner）](https://www.youtube.com/c/JasonTurner) — 每周一个 C++ 技巧，进阶期长期跟
- B 站搜索：「C++ 黑马程序员」「C++ 陈皓」或直接搜 learncpp 讲解
- [CppCon 演讲合集](https://www.youtube.com/user/CppCon)（"Back to Basics" 系列最适合复习）

### 工具（精通 C++ 的标配）

| 工具 | 用途 |
| --- | --- |
| [Compiler Explorer](https://godbolt.org/) | 在线看 C++ → 汇编，验证优化行为，复习期第一神器的兄弟 |
| [C++ Insights](https://cppinsights.io/) | 看编译器如何"展开"你的代码（lambda→类、auto→具体类型） |
| Sanitizers（ASan/UBSan/TSan） | 编译选项级 UB/内存/线程错误检测，比 printf 调试高效 |
| [quick-bench](https://quick-bench.com/) | 在线微基准测试 |
| [Compiler Support Table](https://en.cppreference.com/w/cpp/compiler_support) | 查各编译器对新特性支持度 |
| CMake + vcpkg/Conan | 构建与依赖管理（现代 C++ 工程必修） |

### 社区

- [r/cpp](https://www.reddit.com/r/cpp/) / [r/cpp_questions](https://www.reddit.com/r/cpp_questions/)
- [Meeting C++](https://meetingcpp.com/) / [C++ 中文圈：知乎 C++ 话题](https://www.zhihu.com/topic/19588888/hot)
- [cppreference 论坛/Stack Overflow c++ 标签](https://stackoverflow.com/questions/tagged/c%2B%2B)

## 三、在售经典书（无官方免费版，按需购买）

| 书 | 定位 | 建议 |
| --- | --- | --- |
| 《Effective Modern C++》（Meyers） | 现代 C++ 条款圣经 | **最值得买的一本**，阶段 2 结束时入手 |

| 《A Tour of C++》第 3 版（Stroustrup） | 薄概览 | 适合快速过一遍全貌 |

> 本资料库不提供任何盗版下载；上述付费书请走京东/当当/图灵/O'Reilly 等正规渠道。
