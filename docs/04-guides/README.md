## 这些技术都是什么？（一句话版）

| 名词 | 一句话 |
|---|---|
| **LangGraph** | 把 Agent 画成一张状态图，状态在节点间流转，支持持久化和循环 |
| **Agent** | 能"思考 + 用工具"的程序，不只是问答，能主动获取信息再回答 |
| **ReAct** | Agent 的工作模式：Reason（思考）+ Act（调工具）循环 |
| **LLM** | 大语言模型，Agent 的"大脑" |
| **MCP** | Model Context Protocol，让 Agent 调用外部工具/资源的标准协议（"USB-C for AI"） |
| **A2A** | Agent2Agent Protocol，让 Agent 之间互相发现和协作的标准 |
| **Skill** | 声明式的能力单元，Agent 按需加载（如"会写邮件""会查股票"） |
| **短期记忆** | 单次对话内的上下文（"你刚才说的XX"） |
| **长期记忆** | 跨对话记住的用户信息（"用户偏好简洁回答"） |
| **用户画像** | 对用户兴趣/偏好的结构化建模（用图数据库表达关系） |
| **Checkpointer** | LangGraph 的状态持久化机制，实现短期记忆 |
| **ReAct 循环** | agent → 判断要不要工具 → 调工具 → 回到 agent 的循环 |
| **Tool calling** | LLM 输出结构化的工具调用请求（函数名+参数），而非自然语言 |

详见各模块文档（`docs/02-modules/`）。
