## 这些技术都是什么？（一句话版）

| 名词 | 一句话 |
|---|---|
| **LangGraph** | 把 Agent 画成一张状态图，状态在节点间流转，支持持久化和循环 |
| **Agent** | 能"思考 + 用工具"的程序，不只是问答，能主动获取信息再回答 |
| **ReAct** | Agent 的工作模式：Reason（思考）+ Act（调工具）循环 |
| **LLM** | 大语言模型，Agent 的"大脑" |
| **MCP** | Model Context Protocol，让 Agent 调用外部工具/资源的标准协议（"USB-C for AI"） |
| **A2A** | Agent2Agent Protocol，让 Agent 之间互相发现和协作的标准 |
| **Skill** | 声明式的能力单元，Agent 按需加载（如"会写邮件""会查股票"） |
| **短期记忆** | 单次对话内的上下文（"你刚才说的XX"） |
| **长期记忆** | 跨对话记住的用户信息（"用户偏好简洁回答"） |
| **用户画像** | 对用户兴趣/偏好的结构化建模（用图数据库表达关系） |
| **Checkpointer** | LangGraph 的状态持久化机制，实现短期记忆 |
| **ReAct 循环** | agent → 判断要不要工具 → 调工具 → 回到 agent 的循环 |
| **Tool calling** | LLM 输出结构化的工具调用请求（函数名+参数），而非自然语言 |
| **工作区 Workspace** | Agent 能动手的目录范围；所有文件操作都被禁闭在里面 |
| **审批闸门** | 写文件/执行命令前停下来问用户，管的是"你知不知情" |
| **人在回路 HITL** | 图中途挂起等人决策，再从原地恢复（靠 LangGraph 的 interrupt） |
| **沙箱 Sandbox** | 限制命令能造成的破坏范围，管的是"同意之后能出多大事" |
| **Landlock** | Linux 内核自带的权限限制机制（5.13+），不需要装额外软件 |
| **bubblewrap** | 一个用 namespace 做隔离的工具，比 Landlock 更强（还能断网） |
| **任务计划 Plan** | 多步任务的待办清单，存在图状态里，给模型当外部记事板 |
| **RAG** | 检索增强生成：先从你的文档里搜相关内容，再让 AI 基于它回答 |
| **Embedding** | 把文字转成一串数字（向量），意思相近的文字向量也相近 |
| **多租户** | 同一套服务给多个组织用，数据互相看不见 |
| **链路追踪 / Span** | 记录一次执行里每一步的耗时和参数，排查"慢在哪"用 |
| **优雅降级** | 非核心依赖挂了（如日志库），主功能仍然可用 |
| **fail-closed** | 安全机制出问题时默认"拒绝"而不是"放行" |

不熟悉这些概念？先读 **[从零读懂 Self-Agent](../00-overview/02-从零读懂.md)**——
它用一句话的完整旅程把所有概念串起来讲，比单独看定义好懂。
