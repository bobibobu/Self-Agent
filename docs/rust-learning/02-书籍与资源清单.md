| 在售版本（纸质/电子收费） | 官方免费版 | 获取方式 |
| --- | --- | --- |
| 《Rust 权威指南》（纸书，电子工业出版社） | The Rust Programming Language 电子版完全免费且持续更新（纸书基于 2018 版，内容偏旧） | ✅ 本地 `books/02`（中文）+ `books/03`（英文）；[在线版](https://doc.rust-lang.org/book/) |
| Rust Atomics and Locks（Mara Bos，O'Reilly） | 作者个人网站全文免费 | ✅ 本地 `books/12`（中文未完）+ `books/13`（英文完整）；[在线版](https://marabos.nl/atomics/) |

## 二、必收藏在线资源

## 三、工具链清单

| 工具 | 用途 | 类比 C++ 世界 |
| --- | --- | --- |
| rustup | 工具链管理（多版本切换） | - |
| cargo | 构建/依赖/测试/发布一体化 | CMake + vcpkg + conan +CTest 合体且更好用 |
| rust-analyzer | IDE 语言服务（VSCode 必装） | clangd |
| clippy | lint，写地道 Rust 的导师 | clang-tidy |
| rustfmt | 格式化，无圣战 | clang-format |
| cargo-expand | 宏展开查看 | clang -E |
| cargo-nextest / criterion | 更好用的测试运行器 / 基准测试 | GoogleTest / Google Benchmark |
