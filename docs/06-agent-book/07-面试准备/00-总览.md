# 面试准备专题：大厂 Agent 岗

> 这是书架的**附录专题**，不是第 7 本书——它是一份聚焦的面试弹药库。
> 专门为「算法/CS 基础薄弱，但深度掌握了 Self-Agent 项目」的求职者写。
>
> 基于字节豆包/阿里/智谱等 2025-2026 真实面经，不确定处标注。

---

## 这份专题解决什么

读完这 4 篇，你能：
- 知道大厂 Agent 岗**真实考什么**（按考频分级）
- 把项目讲到**抗八层追问**
- 三大难题（幻觉/漂移/缓存）有**标准答题模板**
- 把薄弱的 CS 基础**挂在项目场景上理解着记**
- 知道算法薄弱**怎么补救**（手撕什么、刷什么）
- 有清晰的 **3-4 个月备考路线**
- 面试时能**聊到各厂业务的点子上**

## 怎么用（按你的情况）

**你是算法薄弱 + CS 基础没系统学**，建议这个顺序：

1. 先读 [④的路线图](04-算法补救与路线图.md)——知道全局怎么安排，定心
2. 重点练 [①的本项目深挖](01-本项目深挖追问.md)——这是你的最大优势，必须打满
3. 背 [②的三大难题模板](02-三大难题问答模板.md)——面试最高频
4. 用 [③的挂钩表](03-考点地图与CS挂钩表.md) 补 CS——理解着记，不死记
5. 按 [④的手撕清单](04-算法补救与路线图.md) 练 Attention 全家桶

## 一个关键判断（给你定心）

**你能进大厂 Agent 岗，尤其是智谱（你用的就是 GLM）和阿里百炼（MCP+A2A 直连）。** 但不是靠运气，是靠「项目深度 + 把算法补到够用 + LLM 八股」。算法是入场券（够用即可，Agent 岗比后端岗门槛低），项目深度才是选拔器——而这是你的强项。

详见 [④的"心理建设"](04-算法补救与路线图.md)。
