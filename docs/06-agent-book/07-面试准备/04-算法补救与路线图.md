## 一、算法薄弱怎么补救（明确结论）

### 先给你定心丸：Agent 岗算法是「入场券」不是「决胜项」

多个面经来源一致结论：
- 算法是**过滤器**（过不了直接挂），但**不是选拔器**（不会拉开巨大差距）
- 难度：**Easy-Medium 为主，Hard 极少**。字节豆包三轮手撕都是 Medium（LC56/LC23/LC416）
- 真正决定录用的是：**项目深度 + 工程能力 + LLM 八股**

**但有个陷阱**：大模型岗有一类**专属手撕题**，后端岗不考——**手写模型组件**（Softmax/Attention/MHA/LayerNorm/FFN）。这类题写不出比 LeetCode 没做出影响**更大**，因为它直接暴露 LLM 基础薄弱。

### 补救策略（按投入产出比排序）

#### 🥇 第一优先：手撕模型组件（范围明确、高频、不考 hard）

这是性价比最高的——范围小、必考、2 周可拿下。按这个清单逐个默写：

1. **Softmax（数值稳定版）**——必考
   - 关键：减最大值防数值溢出
2. **Scaled Dot-Product Attention**——必考
   - `softmax(QK^T/√d)V`，√d 防内积过大梯度消失
3. **Multi-Head Attention**——高频
   - Q/K/V 投影→reshape 多头→并行→concat→输出投影
4. **LayerNorm / RMSNorm**——高频
   - LayerNorm 减均值除标准差；RMSNorm 只除 RMS（省均值计算）
5. **FFN(SwiGLU)**——进阶
   - 门控激活，LLaMA 系用

**怎么练**：每天默写 1 个，2 周烂熟。面试时哪怕 LeetCode 卡壳，这几个写出来就证明 LLM 基础扎实。

#### 🥈 第二优先：LeetCode Hot 100 的 Easy + 常见 Medium

刷 **100-150 题够用**，不必追求 300+。重点这些类型：

| 类型 | 为什么考 | 重点题 |
|---|---|---|
| 数组/哈希 | 基本功 | 两数和、三数和 |
| 双指针 | 基本功 | 快慢指针、滑窗 |
| 二叉树 | 递归思维 | 遍历、最近公共祖先 |
| 链表 | 指针操作 | 反转、合并（LC23 豆包真题） |
| 简单 DP | 豆包爱考 | 分割等和子集（LC416 豆包真题）、合并区间（LC56 豆包真题） |

#### 🥉 第三优先：DP 专项（豆包爱考）

豆包三轮有 DP 题。针对性练 **10-15 道**：
- 背包问题（分割等和子集是 0-1 背包）
- 区间 DP（合并区间变形）
- 简单一维 DP（爬楼梯、打家劫舍）

### 面试时的算法策略

1. **先讲思路再写代码**——面试官更看沟通与思路，写不出最优解就先给暴力解再优化
2. **写不出 LeetCode 但手撕了 Attention**——能证明 LLM 基础，部分挽回
3. **诚实**：不会就说"这块我练过但没练熟，思路是 XX"——比硬编好

## 二、3-4 个月备考路线图（按投入产出比）

### 第 1 个月：把最大优势（项目）打到满分 + 补 LLM 八股

**这是最高优先级——你的项目深度是唯一能碾压科班选手的点。**

- ✅ **Self-Agent 项目梳理到「抗八层追问」**：
  - 用 [面试①](01-本项目深挖追问.md) 的问答清单，每题能 30 秒电梯陈述 + 2 分钟展开
  - 重点：MCP vs A2A 区别、四层记忆理由、三层安全怎么防误删/注入、Agent 死循环兜底、延迟怎么降、为什么手搓、重做怎么 replan
  - **你做的 prompt caching 改造是最新鲜弹药，反复练讲**
- ✅ **LLM 八股速过**：用卡码笔记/小林 coding 过一遍——RAG、Agent、Transformer、幻觉、记忆、采样参数、LoRA/RLHF/DPO
  - 重点"能说清解决什么问题+场景"，**不推公式**（推 PPO 是红线）
  - **RAG 全链路 + Agent 机制每天都要能讲**
- ✅ **三大难题问答模板**（[面试②](02-三大难题问答模板.md)）背熟

### 第 2 个月：手撕 + 中等算法

- ✅ **手撕模型组件**：Softmax/Attention/MHA/LayerNorm/FFN，每天 1 个，2 周烂熟
- ✅ **LeetCode Easy + 常见 Medium**：100 题，优先 Hot 100
- ✅ **系统设计题专项**：用 [书1第 12 章](../01-全书/12-完整链路拆解.md) + [第 11 章](../01-全书/11-企业能力.md) 的架构，准备 2-3 个案例（RAG 系统、多轮对话系统、客服 Agent）

### 第 3 个月：补短板 + 模拟面

- ✅ **后端八股急救**（看 JD 偏工程还是算法）：Redis、MySQL、Kafka、HTTP、并发。用 [面试③ CS 挂钩表](03-考点地图与CS挂钩表.md) 挂项目记
- ✅ **各厂业务理解**：读目标厂 Agent 平台文档（百炼/千帆/Coze/元器），准备 1-2 个"我对贵厂 XX 产品的观察"（豆包三面会问）
- ✅ **模拟面试**：找同行 mock，专练项目深挖的抗压追问

### 第 4 个月（缓冲/冲刺）

- ✅ 查漏补缺，按真实面经（字节豆包三轮、小米二面 RAG 排障）全真模拟
- ✅ **投递策略**：**先面中小厂热身**，再冲大厂。算法薄弱直接冲字节一面可能被卡，先用中小厂攒面试感

### 一句话策略

> **「项目深度 + LLM 八股 + 手撕 Attention」是必须拿满的基本盘；「中等算法题」是入场券（够用即可）；用项目深度弥补算法中等——这是 Agent 应用岗的最大红利，也是你该利用的结构性优势。**

## 三、各厂 Agent 业务现状（面试聊天用）

让你面试时能聊到点子上，显得"懂行"。基于 2026-08 调研，时效性强，面试前建议再核实最新动态。

### 总览表

| 厂商 | 基座模型 | Agent 平台 | 2025-2026 关键动态 |
|---|---|---|---|
| **字节** | Doubao-Seed-2.0 | **扣子/Coze**、即梦、Seedance | 日均 50 万亿 Tokens；重点「生产力 Agent + Coding」；开源 **Eino**（Go Agent 框架） |
| **阿里** | 通义 Qwen | **百炼**、AgentScope | 业界首个全生命周期 **MCP 服务**；百炼支持 **A2A** 直连；AgentScope 2.0（2026.6 企业级分布式） |
| **智谱** | GLM-4.5 | **AutoGLM 沉思**、GLM-PC | **AutoGLM 2.0**（全球首个手机 Agent）；**CogAgent-9B 开源**——**注意：你的项目默认用 GLM** |
| **腾讯** | 混元 Hy3 | **元宝**、元器、TokenHub | Agent 产品全景图；探索微信 Agent；Hy3 已开源 |
| **百度** | 文心 5.0 | **千帆**、AppBuilder | 千帆 Agent Infra 五层；**承载超 130 万智能体** |
| **月之暗面** | Kimi K2 | Kimi | 战略核心是**长上下文**（消费端 200 万字）；K2 强化 Agent+编码 |

### 面试可主动聊的行业趋势（加分）

1. **Agent 从「单次推理」走向「自主闭环执行」**
2. **MCP（工具）+ A2A（协作）成为 Agent 通信标准**——你项目正是这个栈，**直接对口**
3. **厂商押注「Agent 平台化」**（百炼/千帆/Coze/元器）
4. **PD 分离、推理优化是工程刚需**——[书⑥第 5 章](../06-进阶技术/05-其他新技术.md)
5. **手机端/端侧 Agent**（AutoGLM、苹果化）是 2026 热点

### 各厂的"面试聊天钩子"

- **字节**：聊 Coze 的 Agent 编排、Eino 的 Go 高性能定位、Seed 团队的 Coding 方向
- **阿里**：聊百炼的 MCP 全生命周期服务、A2A 直连、AgentScope 的分布式
- **智谱**：**聊你项目用的就是 GLM**——这是天然亲近点；聊 AutoGLM 的手机 Agent、CogAgent 开源
- **腾讯**：聊元宝的免费 Agent、微信 Agent 探索
- **百度**：聊千帆的 130 万智能体规模、AppBuilder 的零代码

### 你的项目对各厂的"对口度"

| 你的栈 | 最对口的厂 |
|---|---|
| **GLM 默认 provider** | ⭐ **智谱**（天然亲近，你就是他们的用户） |
| **MCP + A2A** | ⭐ **阿里百炼**（业界首个 MCP 服务 + A2A 直连） |
| **LangGraph** | 字节（也用类似图编排）、阿里（AgentScope） |
| **编码 Agent**（三层安全） | 字节 Seed（Coding 方向）、各家 IDE Agent |

**智谱和阿里百炼是你最对口的目标**——技术栈直接命中。

## 四、最后给你的心理建设

### 你的真实优势（别妄自菲薄）

1. **项目深度碾压大多数候选人**——市面上大量候选人停在"用过 LangChain 调过 API"，你能讲透 checkpointer/reducer/interrupt、MCP vs A2A、三层安全、四层记忆、还做了 prompt caching 改造
2. **Agent 赛道极热**——门槛相对低于纯算法岗，需求真实
3. **你的技术栈对口智谱/阿里**——GLM + MCP + A2A 是这两个厂的核心

### 你的真实短板（清醒补）

1. **算法**——必须补到 Medium 能写（入场券）
2. **CS 基础**——用 [挂钩表](03-考点地图与CS挂钩表.md) 挂项目理解着记
3. **LLM 底层手撕**——Softmax/Attention 必须默写

### 一个诚实的预期

- **3-4 个月认真准备**（按上面路线图）→ **大厂 Agent 岗是有机会的**，尤其智谱/阿里百炼这种技术栈对口的
- 但**不要直接冲字节一面**（算法可能卡）——先用中小厂热身，攒面试感再冲大厂
- 算法和 CS 基础是硬通货，**没有捷径**，但 Agent 岗的算法门槛比后端岗低，你用项目深度补

**你能进大厂，但不是靠运气，是靠"项目深度 + 把算法补到够用 + LLM 八股"。这条路是清楚的，剩下的就是执行。**
