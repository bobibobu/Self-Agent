# 第 1 章：Transformer 与 Attention

> 这章讲透 `softmax(QK^T/√d)V` 的每一项为什么这样设计。这是大模型岗**最高频追问**，也是手撕题的基础。

---

## 1.1 一句话先建立直觉

Transformer 的核心是 **Self-Attention（自注意力）**：让序列里每个 token "看"其他所有 token，决定该关注谁。它干的事是"**加权求和**"——每个 token 的新表示 = 所有 token 表示的加权和，权重由"相似度"决定。

---

## 1.2 Q、K、V 是什么

每个 token 的嵌入（embedding）经过三个不同的线性变换，得到三个向量：

| 向量 | 含义 | 比喻 |
|---|---|---|
| **Q（Query）** | "我在找什么" | 搜索查询 |
| **K（Key）** | "我能提供什么" | 文档关键词 |
| **V（Value）** | "我的实际内容" | 文档正文 |

**直觉**：token A 用自己的 Q 去和所有 token 的 K 算相似度（点积），相似度高的 token，A 就多吸收它的 V。

---

## 1.3 公式拆解：`softmax(QK^T/√d)V`

逐项解释（**面试必答**）：

### ① `QK^T`——算相似度

Q 是 `(seq_len, d)`，K 也是 `(seq_len, d)`。`QK^T` 是 `(seq_len, seq_len)` 的矩阵，第 i 行 j 列 = 第 i 个 token 的 Q 和第 j 个 token 的 K 的点积。

**点积 = 相似度**（两个向量越接近，点积越大）。这一步算出了"每个 token 对其他所有 token 的关注程度（原始分数）"。

### ② `/√d`——缩放（关键，面试爱问为什么）

d 是向量维度（如 64）。为什么要除以 √d？

**答**：防止点积过大导致 softmax 梯度消失。

- 点积的方差随 d 增大而增大（d 个分量的和）
- 点积很大 → softmax 输出接近 one-hot（一个 1，其余 0）→ 梯度几乎为 0 → 训练停滞
- 除以 √d 把方差拉回 1 附近，让 softmax 处于"温和"区间

**面试一句话**：「√d 缩放防止内积过大导致 softmax 进入梯度饱和区」。

### ③ `softmax`——归一化成权重

把每一行的原始分数转成概率分布（和为 1）。这样每个 token 对其他 token 的关注程度是个"权重"。

### ④ `·V`——加权求和

用权重对 V 加权求和，得到每个 token 的新表示。

**完整直觉**：`softmax(QK^T/√d)` 算出"谁该关注谁"的权重矩阵，再乘 V 得到加权后的新表示。

---

## 1.4 Multi-Head Attention（MHA）

单头注意力只有一个"关注模式"。多头是**并行做多组 Q/K/V**，每组学不同的关注模式，最后 concat 起来。

**为什么多头**：语言里有多种关系（语法、语义、共指等），单头学不过来，多头让模型同时捕捉多种关系。

**维度分配**：如果 d_model=512、8 头，每头 d=64。8 头并行算，concat 后还是 512，再过一次线性投影。

→ 手撕实现见 [第 6 章](06-手撕详解.md)。

## 1.5 位置编码（Positional Encoding）

Attention 本身是**顺序无关**的（打乱 token 顺序结果一样，因为是对所有 token 加权）。但语言有顺序，所以要注入位置信息。

### 三代位置编码

| 方案 | 原理 | 代表 |
|---|---|---|
| **绝对位置编码（正弦）** | 用 sin/cos 不同频率编码位置 | 原始 Transformer |
| **可学习位置编码** | 每个位置一个可训练向量 | GPT-2/BERT |
| **RoPE（旋转位置编码）** | 把位置信息编进 Q/K 的旋转 | LLaMA/GLM/Qwen 等主流 |

### RoPE（面试爱问：加在 Q 还是 K？）

**答：加在 Q 和 K 上**（不是 V）。

- 原理：对 Q 和 K 做旋转矩阵乘法，旋转角度由位置决定
- **形式是绝对编码**（每个位置一个固定旋转），**效果是相对编码**（Q·K 的点积只依赖相对位置）
- 优点：支持长上下文外推（相对位置泛化好）

**为什么不加 V**：V 是"内容"，旋转它没意义；位置信息体现在"Q 找 K"的匹配过程里。

---

## 1.6 为什么 Decoder-only 成主流

（豆包二面真题）相比 Encoder-Decoder（如 T5）：

1. **训练-推理一致**：Decoder-only 训练时就是"预测下一个 token"，推理时也是，没有 train-test mismatch
2. **Scaling Law 更好**：实验表明 Decoder-only 在 scale up 时收益更稳
3. **省 Encoder 开销**：贪心解码下不需要 encoder
4. **统一架构**：一个 Transformer 堆栈搞定一切，工程简单

## 1.8 面试速答卡

> **Q：Self-Attention 是什么？**
> A：`softmax(QK^T/√d)V`。Q/K/V 是 token 嵌入的三次线性变换；QK^T 算相似度；√d 防梯度消失；softmax 归一化成权重；乘 V 加权求和得新表示。

> **Q：为什么除以 √d？**
> A：防止点积过大导致 softmax 梯度饱和。点积方差随维度增大，除以 √d 拉回 1。

> **Q：RoPE 加在 Q 还是 K？**
> A：Q 和 K 都加（不加 V）。形式绝对、效果相对。
