# 第 5 章：采样、量化、Speculative Decoding

> 温度/top-p/top-k 是 Agent 岗**问得最深**的（[面试③](../07-面试准备/03-考点地图与CS挂钩表.md) 必考）。这章讲透它们各自改变什么。加量化、speculative decoding。

---

## 5.1 LLM 怎么生成下一个 token

LLM 最后输出的是**整个词表的概率分布**（logits → softmax → 概率）。生成下一个 token 就是"按这个分布**采样**"。

采样策略决定了"怎么从分布里挑 token"，直接影响生成质量/多样性。

---

## 5.2 三个核心采样参数

### ① 温度（Temperature）

**原理**：给 logits 除以温度 T，再 softmax。

```
原始 logits: [2.0, 1.0, 0.5]
T=1.0:  正常 softmax  → 概率分布 P
T=0.5:  logits × 2    → 分布更"尖"（大概率更突出）
T=2.0:  logits × 0.5  → 分布更"平"（概率趋近均匀）
```

**效果**：
- **T 低（如 0.1）**：分布变尖 → 几乎总选最高概率 token → **确定性、保守、重复**
- **T 高（如 1.5）**：分布变平 → 低概率 token 也有机会 → **多样、有创意、可能乱说**
- **T=0**：greedy，永远选最高 → 完全确定（Self-Agent 的摘要生成用低 T）

**Agent 场景**：工具调用、代码生成用低 T（要准）；创意写作用高 T（要多样）。Self-Agent 默认 0.7（折中）。

### ② Top-k

**原理**：只从概率最高的 **k 个** token 里采样，其余直接丢弃。

- k=1：greedy（只选最高）
- k=50：只在前 50 个里选

**效果**：截断长尾，避免选到极低概率的"乱码"token。但 k 是固定的——不管分布是尖是平都截同样多。

### ③ Top-p（Nucleus Sampling）

**原理**：把 token 按概率从高到低排序，累计概率**达到 p 就停**，只在这个"核"里采样。

- p=0.9：累计到 90% 概率的那些 token，剩下的丢
- 动态的：分布尖时核小（几个 token 就到 90%），分布平时核大（很多 token 才到 90%）

**效果**：比 top-k 更聪明——分布尖时少选、分布平时多选，自适应。

### 三者对比

| 参数 | 改变什么 | 优点 | 缺点 |
|---|---|---|---|
| 温度 T | 分布的"陡峭程度" | 控制保守/创意 | 不截断尾部 |
| top-k | 固定截断到 k 个 | 简单 | 不自适应分布形状 |
| top-p | 动态截断到累计概率 p | 自适应 | 需要排序 |

**实战**：经常组合用，如 top-p=0.9 + temperature=0.7。

## 5.3 量化（Quantization）

**原理**：把模型参数从 FP16（16 位浮点）降到 INT8/INT4（8/4 位整数），省显存、提速。

### 为什么有效

- FP16 参数占 2 字节，INT4 占 0.5 字节 → **显存省 4 倍**
- 整数运算比浮点快
- 牺牲少量精度（通常掉几个百分点 benchmark）

### 常见方案

| 方案 | 位宽 | 特点 |
|---|---|---|
| INT8 | 8 bit | 精度损失小，通用 |
| INT4 | 4 bit | 省显存明显，损失稍大 |
| FP8 | 8 bit 浮点 | NVIDIA H100 支持，精度更好 |
| GPTQ/AWQ | 4 bit | 主流 4-bit 量化算法 |

**QLoRA** 就是"基模 4-bit 量化 + LoRA 微调"——省显存微调（[书⑥第 5 章](../06-进阶技术/05-其他新技术.md)）。

## 5.4 Speculative Decoding（推测解码）

**原理**：用小"草稿模型"快速预生成几个 token，大模型并行验证，命中就整段接受、不命中丢弃。**数学上无损**。

### 为什么快

- 大模型逐 token 生成慢（decode 访存密集）
- 小模型生成快（参数少）
- 大模型并行验证 k 个 token ≈ 生成 1 个 token 的时间
- 命中 k 个就等于一次推进 k 个 → 加速

### 加速比

取决于草稿模型质量和接受率，通常 1.4x-4x。短输出收益小（[书⑥第 5 章](../06-进阶技术/05-其他新技术.md)）。

### 谁支持

vLLM 原生支持 Eagle 3、N-gram、draft model 等。**只自托管时相关**（Self-Agent 用云端 API 无关）。

## 5.6 面试速答卡

> **Q：温度/top-p/top-k 分别改变什么？**
> A：温度改分布陡峭程度（低=保守、高=创意）；top-k 固定截断到 k 个；top-p 动态截断到累计概率 p（自适应分布形状）。常组合用。

> **Q：量化为什么省显存？**
> A：FP16→INT4 参数占的字节少 4 倍，整数运算更快，牺牲少量精度换显存和速度。

> **Q：Speculative Decoding 为什么无损？**
> A：小模型预生成，大模型并行验证——接受概率服从原始分布，数学上和直接用大模型采样等价，只是更快。
