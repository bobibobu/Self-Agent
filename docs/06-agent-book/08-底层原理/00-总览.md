## 这本书解决什么

读完这本，你能回答：

- Self-Attention 的 `softmax(QK^T/√d)V` 每一项为什么这样设计？
- KV Cache 到底缓存了什么？为什么前缀改一个 token 整条失效？（和你做的 prompt caching 改造连起来）
- 为什么 prefill 慢、decode 快？这对 Agent 的首字延迟意味着什么？
- 向量检索的 HNSW/IVF 索引怎么工作？为什么 pgvector 比 Qdrant 慢？
- vLLM 的 PagedAttention 借鉴了 OS 的什么？SGLang 的 RadixAttention 强在哪？
- 温度/top-p/top-k 采样各自改变什么？量化为什么省显存？
- **手撕**：Softmax 数值稳定版、Scaled Dot-Product Attention、Multi-Head Attention 怎么写？
