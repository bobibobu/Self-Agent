## 6.1 Softmax（数值稳定版）—— 必考

### 原理

把任意实数向量转成概率分布（和为 1）。`softmax(x_i) = exp(x_i) / Σexp(x_j)`。

**陷阱**：直接 `exp` 会数值溢出（如 x=[1000, 1001]，exp(1000) = inf）。

**解法**：减最大值。`softmax(x_i) = exp(x_i - max) / Σexp(x_j - max)`。减同一个常数不改变 softmax 结果（分子分母同除），但把 exp 的输入拉到 ≤0，不会溢出。

### 代码（逐行注释）

```python
import torch

def softmax(x, dim=-1):
    """数值稳定的 softmax。
    
    Args:
        x: 任意形状的张量
        dim: 沿哪个维度做 softmax（通常是最后一维）
    """
    # 减最大值防溢出——这是"数值稳定版"的关键
    # keepdim=True 让 max 的形状能和 x 广播相减
    x_max = torch.max(x, dim=dim, keepdim=True).values
    x_shifted = x - x_max
    
    # exp（此时输入 ≤0，不会溢出）
    exp_x = torch.exp(x_shifted)
    
    # 归一化成概率（和为 1）
    sum_exp = torch.sum(exp_x, dim=dim, keepdim=True)
    return exp_x / sum_exp

# 验证
x = torch.tensor([1.0, 2.0, 3.0])
print(softmax(x))  # tensor([0.0900, 0.2447, 0.6652])，和为 1
```

### 面试考点

- **为什么减最大值**：防 exp 溢出；减常数不改变 softmax 结果（分子分母同除）
- **keepdim 为什么**：让 max 形状能广播相减
- **dim 参数**：softmax 沿哪个维度归一化

## 6.2 Scaled Dot-Product Attention —— 必考

### 公式

`Attention(Q, K, V) = softmax(QK^T / √d_k) V`

### 代码（逐行注释）

```python
import torch
import torch.nn.functional as F
import math

def scaled_dot_product_attention(Q, K, V, mask=None):
    """Scaled Dot-Product Attention。
    
    Args:
        Q: (batch, ..., seq_q, d_k)  查询
        K: (batch, ..., seq_k, d_k)  键
        V: (batch, ..., seq_k, d_v)  值
        mask: 可选，屏蔽某些位置（如因果 mask 防看未来）
    Returns:
        output: 加权后的 V
        weights: attention 权重（可解释性用）
    """
    d_k = Q.shape[-1]
    
    # ① QK^T：算相似度。(seq_q, d_k) @ (d_k, seq_k) → (seq_q, seq_k)
    # K.transpose(-2, -1) 交换最后两维
    scores = torch.matmul(Q, K.transpose(-2, -1))
    
    # ② /√d_k：缩放防梯度消失（详见第 1 章）
    scores = scores / math.sqrt(d_k)
    
    # ③ 应用 mask（如果有）：把要屏蔽的位置设成负无穷，
    # 这样 softmax 后这些位置权重为 0
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    
    # ④ softmax 归一化成权重
    weights = F.softmax(scores, dim=-1)
    
    # ⑤ 加权求和 V：(seq_q, seq_k) @ (seq_k, d_v) → (seq_q, d_v)
    output = torch.matmul(weights, V)
    
    return output, weights

# 验证
Q = torch.randn(1, 4, 8)   # batch=1, seq=4, d=8
K = torch.randn(1, 4, 8)
V = torch.randn(1, 4, 8)
out, w = scaled_dot_product_attention(Q, K, V)
print(out.shape)  # torch.Size([1, 4, 8])
print(w[0].sum(-1))  # 每行和为 1
```

### 面试考点

- **QK^T 算什么**：相似度（点积）
- **为什么 /√d_k**：防点积过大导致 softmax 梯度消失（第 1 章）
- **mask 干嘛**：因果 mask 防 decoder 看未来；padding mask 忽略填充位
- **masked_fill(-inf)**：被屏蔽位置 softmax 后权重为 0

## 6.3 Multi-Head Attention —— 高频

### 原理

并行做多组 Q/K/V（多头），每组学不同关注模式，concat 后投影。

### 代码（逐行注释）

```python
import torch
import torch.nn as nn
import math
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        """d_model 必须能被 num_heads 整除。"""
        super().__init__()
        assert d_model % num_heads == 0, "d_model 必须能被头数整除"
        
        self.d_model = d_model        # 总维度（如 512）
        self.num_heads = num_heads    # 头数（如 8）
        self.d_k = d_model // num_heads  # 每头维度（如 64）
        
        # 4 个线性投影：Q、K、V 的输入投影 + 输出投影
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def forward(self, x, mask=None):
        """
        Args:
            x: (batch, seq_len, d_model)
            mask: 可选
        """
        batch_size, seq_len, _ = x.shape
        
        # ① 线性投影 Q/K/V：(batch, seq, d_model) → (batch, seq, d_model)
        Q = self.W_q(x)
        K = self.W_k(x)
        V = self.W_v(x)
        
        # ② reshape 成多头：(batch, seq, d_model) → (batch, seq, num_heads, d_k) → (batch, num_heads, seq, d_k)
        # transpose 让"头"维度在前，方便各头独立做 attention
        Q = Q.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        
        # ③ 各头并行做 attention（复用 6.2 的函数）
        # mask 要广播到头维度
        if mask is not None:
            mask = mask.unsqueeze(1)  # (batch, 1, seq, seq) 广播到所有头
        attn_out, _ = scaled_dot_product_attention(Q, K, V, mask)  # 复用上面的函数
        
        # ④ concat 头：(batch, num_heads, seq, d_k) → (batch, seq, num_heads, d_k) → (batch, seq, d_model)
        attn_out = attn_out.transpose(1, 2).contiguous().view(batch_size, seq_len, self.d_model)
        
        # ⑤ 输出投影
        return self.W_o(attn_out)

# scaled_dot_product_attention 复用 6.2 的实现
# 验证
mha = MultiHeadAttention(d_model=512, num_heads=8)
x = torch.randn(2, 10, 512)  # batch=2, seq=10, d_model=512
out = mha(x)
print(out.shape)  # torch.Size([2, 10, 512])
```

### 面试考点

- **为什么多头**：单头只学一种关注模式，多头并行学多种（语法、语义、共指等）
- **reshape + transpose**：`(batch, seq, d_model) → (batch, heads, seq, d_k)` 让各头独立
- **contiguous()**：transpose 后内存不连续，view 前要 contiguous
- **维度分配**：d_model=512、8 头 → 每头 64，concat 回 512

## 6.4 LayerNorm —— 高频

### 原理

对每个样本的特征维度归一化（减均值除标准差），稳定训练。

### LayerNorm vs BatchNorm

- **BatchNorm**：对一批样本的**同一特征**归一化（依赖 batch，CV 用）
- **LayerNorm**：对**单个样本的所有特征**归一化（不依赖 batch，NLP/Transformer 用）

为什么 Transformer 用 LayerNorm：序列长度可变、batch 内样本异质，BatchNorm 不合适。

### 代码

```python
import torch
import torch.nn as nn

class LayerNorm(nn.Module):
    def __init__(self, features, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(features))  # 可学习的缩放
        self.beta = nn.Parameter(torch.zeros(features))   # 可学习的偏移
        self.eps = eps
    
    def forward(self, x):
        # 沿最后一维（特征维）算均值和方差
        mean = x.mean(dim=-1, keepdim=True)
        var = x.var(dim=-1, keepdim=True, unbiased=False)
        # 归一化
        x_norm = (x - mean) / torch.sqrt(var + self.eps)
        # 缩放偏移
        return self.gamma * x_norm + self.beta
```

### RMSNorm（LLaMA/GLM 用）

RMSNorm 是 LayerNorm 的简化——**省掉减均值**，只除 RMS（均方根）：

```python
class RMSNorm(nn.Module):
    def __init__(self, features, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(features))
        self.eps = eps
    
    def forward(self, x):
        # 只除 RMS，不减均值——省计算
        rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps)
        return self.weight * (x / rms)
```

**为什么用 RMSNorm**：实验表明效果和 LayerNorm 差不多，但省了减均值的开销，推理更快。
