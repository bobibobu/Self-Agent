## 自主 vs 约束（核心框架）

这是理解本系列最重要的二分法：

| 维度 | 自主 Agent（autonomous） | 约束式 Agent（constrained，Self-Agent） |
|---|---|---|
| 目标 | 给个目标自己跑到底 | 每步在人监督下执行 |
| 循环 | **self-prompting**（自己给自己生成下一步） | ReAct（人在回路审批） |
| 安全 | 弱（信任 agent 自主） | 强（工作区+审批+沙箱） |
| 失败模式 | 跑偏、死循环、烧钱 | 被人拦下、可恢复 |
| 代表 | AutoGPT、MetaGPT | Claude Code、Self-Agent |

**关键认知**：AutoGPT 那一代证明了「自主循环」可行，但也暴露了**无约束自主性的灾难**。Self-Agent 的「审批+沙箱+工作区禁闭」正是对这一代教训的回应。

**业界趋势**：从「无约束自主」转向「约束式 Agent」——给人监督权，给 agent 沙箱边界。Self-Agent 站在这个趋势的正确一边。
