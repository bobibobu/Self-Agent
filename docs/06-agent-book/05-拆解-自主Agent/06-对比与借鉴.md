# 第 6 章：和 Self-Agent 的范式对比与借鉴

> 把前 5 章收口：Self-Agent 在自主 Agent 和记忆层这两类项目里是什么位置？哪些可以借鉴？

---

## 6.1 范式对比：自主 vs 约束（Self-Agent 的根本立场）

| 维度 | AutoGPT（自主） | MetaGPT（自主+SOP） | **Self-Agent（约束）** |
|---|---|---|---|
| 循环 | self-prompting（无人值守） | SOP 驱动（流程自治） | ReAct + 人在回路 |
| 安全 | 弱 | 弱 | **工作区+审批+沙箱** |
| 失败 | 跑偏/死循环/烧钱 | 流程死板 | **被人拦下/可恢复** |
| 任务列表 | create/prioritize/execute | SOP 固化 | **update_plan（带约束）** |
| 多 agent | 无 | 角色剧本 | **A2A 标准协议** |

### Self-Agent 的根本立场

**约束式 Agent**——给 agent 自主性，但用审批+沙箱+recursion_limit 约束。这是对 AutoGPT/MetaGPT 那一代「无约束自主」教训的回应。

**业界趋势印证这个选择是对的**：Claude Code、Cline 都在走向约束式。

## 6.2 记忆对比：Self-Agent 四层在全景中的位置

| 方案 | Self-Agent 对比 |
|---|---|
| AutoGPT（简单向量库） | Self-Agent 四层**更丰富** |
| MetaGPT（结构化制品） | Self-Agent 存事实，**不存制品**——可借鉴 |
| MemGPT/Letta（agent 自管） | Self-Agent **系统自动**，不如 MemGPT 智能——可借鉴 |
| Mem0（抽取+多跳） | Self-Agent 抽取+单跳，Mem0 **多跳更强**——可借鉴 |

### Self-Agent 记忆的定位

- **丰富度领先**：四层是表里最丰富的
- **智能度居中**：系统自动（不如 MemGPT 的 agent 自管）
- **结构化偏弱**：自由文本（不如 MetaGPT/Aider 结构化）

## 6.3 给 Self-Agent 的借鉴建议（汇总）

### 来自自主 Agent

| 借鉴 | 来源 | 优先级 | 难度 | 收益 |
|---|---|---|---|---|
| **update_plan 加优先级** | AutoGPT BabyAGI | ★★ | 低 | 多任务排序 |
| **token 预算控制** | AutoGPT 烧钱教训 | ★★ | 中 | 防失控 |
| **长期记忆存制品** | MetaGPT | ★ | 高 | 长任务支持 |
| **SOP 作为可选模式** | MetaGPT | ★ | 高 | 垂直场景 |

### 来自记忆层

| 借鉴 | 来源 | 优先级 | 难度 | 收益 |
|---|---|---|---|---|
| **多跳查询**（画像层） | Mem0 | ★★ | 中 | 复杂画像分析 |

## 6.4 重点解读

### 借鉴①：token 预算控制（来自 AutoGPT 教训，高优先级）

AutoGPT 烧钱的教训说明：自主循环必须有**显式预算控制**。

Self-Agent 有 recursion_limit（步数控制），但**没有 token 预算控制**。可加一个「单次任务最多花多少 token」的限制——超过就停下来问用户。这能防失控烧钱。

### 借鉴②：多跳查询（来自 Mem0，中优先级）

Self-Agent 的画像层已经是 Neo4j（图库），天然支持多跳。可加一个「多跳查询」能力：
- 「和用户兴趣相似的其他用户也喜欢什么」
- 「用户的偏好如何影响推荐」

这比单跳语义检索更适合复杂画像分析。

### 借鉴③：长期记忆存制品（来自 MetaGPT，长期方向）

Self-Agent 的长期记忆存「从对话抽取的事实」。如果要做「能交付完整项目的 agent」，可借鉴 MetaGPT，让记忆系统也存**结构化制品**：
- 计划文档（update_plan 的历史）
- 设计决策（关键 diff）
- 验收标准

这让长任务有更扎实的上下文。

### 借鉴④：update_plan 加优先级（来自 AutoGPT，低难度）

Self-Agent 的 update_plan 是 BabyAGI 任务列表的简化，但**没优先级**。可让模型给任务标优先级，多任务时知道先做哪个。改动小，收益明确。

## 6.5 Self-Agent 已有优势（保持）

### 优势①：约束设计最完善

审批 + 沙箱 + recursion_limit + 四档策略。避免了 AutoGPT 的自主性灾难。**这是 Self-Agent 相对自主 Agent 的核心优势**。

### 优势②：四层记忆最丰富

短/长/画像/日志各司其职，比 AutoGPT/Mem0 单层更系统。

### 优势③：Hermes 自我进化

兼顾了 Reflexion（反思）+ 记忆学习。是自主 Agent「越用越聪明」的工程实现——但是**约束式**的（评分阈值、可回滚、手动触发），不会失控。

### 优势④：A2A 标准化多 agent

比 MetaGPT 的固定角色剧本更开放、通用。

---

## 6.6 一个诚实的总结：自主 Agent 这一类

自主 Agent 这一类项目，**历史意义 > 当前工程价值**：

- **AutoGPT**：开创品类，但代码粗糙、无约束自主性已被证明不可行
- **MetaGPT**：SOP 思想有价值，但「模拟软件公司」场景太窄
- **MemGPT/Letta**：上下文管理思想超前，但学习曲线陡，未主流
- **Mem0**：实用，但只是记忆层，不是完整 Agent

**趋势**：业界从「无约束自主」转向「约束式 Agent」（Claude Code、Self-Agent）——给人监督权，给 agent 沙箱边界。这是对 AutoGPT 那一代教训的集体回应。

**Self-Agent 站在这个趋势的正确一边**：约束式 + 多层记忆 + 标准协议。

---

## 6.7 这本书的核心结论

1. **自主 vs 约束是根本二分**：Self-Agent 是约束式，是对 AutoGPT 教训的回应
2. **AutoGPT 的教训**：无约束自主会跑偏/死循环/烧钱——约束是必需品
3. **MetaGPT 的 SOP 思想**：流程先行有价值，但场景窄；Self-Agent 选协议先行更通用
4. **MemGPT 做上下文管理，Mem0 做记忆存储**：两种记忆哲学，前者智能但复杂，后者实用
5. **Self-Agent 四层记忆最丰富**，智能度居中（系统自动），可借鉴多跳/制品/agent 自管
6. **业界趋势**：约束式 Agent 是方向，Self-Agent 站对边
