# Agent 开阶学习书架

> 这是一套**面向零基础到面试/实战**、目标是「读完就能掌握 Agent 开发全领域」的学习文档。
> 以本项目 [Self-Agent](../../README.md) 为蓝本，结合市面上最值得学习的开源项目。
>
> **整套是 6 本独立的「书」**：
> - 第 1 本：**基础全书**（基于当前项目，把所有概念讲透）
> - 第 2-5 本：四类开源项目的**拆解专书**，每本都是独立的多章节书
> - 第 6 本：**进阶技术**（幻觉/漂移/缓存三大难题 + 2026 新技术 + 最强开源 Agent 栈）

## 这套书是给谁看的

- **没接触过 Agent**，刚打开 Self-Agent 仓库不知道从哪看起的人

## 怎么读

**完全零基础**：从第 1 本开始通读。第 1 本是地基，把「状态存什么、message 什么形式」这类基础疑问彻底讲透。

**有基础、想深入某个开源项目**：直接翻第 2-5 本对应的拆解书，每本独立，无先后。

**想查某个概念**：看 [第 1 本第 15 章 术语速查](01-全书/15-术语速查与延伸阅读.md)。

## 关于这套书的事实声明

- **第 1 本（基于本项目）**：所有代码引用都带文件与行号，已逐一验证准确；写作时基于当前代码库的真实实现。
- **第 2-5 本（开源项目）**：star 数等会随时间变化，书中标注「调研时点（2026-08）」并建议核实；设计思想来自各项目官方博客/规范/权威逆向分析，凡无法确认的均标注。
- **不做的事**：不编造项目、机制或数字；不把推测当事实。
