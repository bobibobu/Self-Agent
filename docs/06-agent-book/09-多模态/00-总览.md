## 一个诚实的基线：Self-Agent 的多模态现状

README 明确列了已知限制：

> 「图片能上传，但 LLM 层 `ChatMessage.content` 只支持纯文本，图片进不了对话」

代码现状（已核实）：
- `ChatMessage.content: str | None`（`app/llm/models.py:30`）——纯字符串
- 上传路由（`app/api/upload_routes.py`）会给图片返回 URL（`is_image: True, url: "/uploads/xxx"`），但**没有任何代码把这个 URL 塞进对话**
- providers（`openai_like.py` / `anthropic.py`）**完全没有 image/vision 处理**

**所以图片上传后是个孤岛**——存在服务器上，Agent 看不到。这本书讲怎么打通。

## 多模态 Agent 的三种形态（2026）

| 形态 | 输入 | 代表 | Self-Agent 现状 |
|---|---|---|---|
| **图片理解** | 用户上传图片 + 提问 | GLM-4.5V / GPT-4V / Claude | ❌ 进不了对话 |
| **视频/文档理解** | 视频帧 / PDF 页 | GLM-4.5V（支持） | ❌ |
| **GUI 操作** | Agent 主动看屏幕/操作 | Computer Use / Browser Use | ❌（但 MCP 可接 browser-use） |

前两种是"用户给 Agent 看图"，第三种是"Agent 自己看屏幕操作"——2026 最火。
