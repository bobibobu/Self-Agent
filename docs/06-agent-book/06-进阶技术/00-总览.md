## 一个贯穿全书的诚实基线

先亮底牌——**当前 Self-Agent 在三大难题上的真实水平**：

| 难题 | 本项目现状 | 评级 |
|---|---|---|
| **幻觉** | 只靠 function calling（算半个 grounding）+ 可选 RAG；**无** citation / 自校验 / critic | ❌ 基本裸奔 |
| **上下文漂移** | ✅ 做了两件：`context_manager`（摘要压缩）+ `update_plan`（外部记事板） | ✅ 做了，方向对 |
| **缓存命中** | ❌ **系统提示每轮动态拼**（含记忆/RAG），前缀不固定 → GLM 的 prompt cache **永远 miss** | ❌ 反模式 |

这本书的每一章都会回到这张表，讲"差在哪、怎么补"。**诚实是这本书的底线**——不粉饰项目现状，也不夸大新技术。
