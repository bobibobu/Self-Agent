# 书②：拆解编码 Agent

> 这是**第 2 本书**，独立成册。
>
> 拆解对象：**编码 Agent**——能读写文件、执行命令、改代码的 Agent。
> 这是和 Self-Agent（工作区禁闭+审批+沙箱）**最对位**的一类项目。
>
> 拆解项目：**Claude Code**（Anthropic 闭源）· **Aider**（开源）· **Cline**（开源）· **Cursor**（闭源）。
> 最后用 Self-Agent 做横向对比。
