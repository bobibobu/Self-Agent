## 0.2 一句话定义 Agent

先把最根本的搞清楚。**Agent（智能体）= 一个能「思考 + 动手」的程序。**

- **思考**：调用大语言模型（LLM），让它决定下一步该干什么。
- **动手**：调用真正的程序功能（读文件、跑命令、查数据库……），把思考变成行动。

关键区别在于「动手」：

```
直接调 ChatGPT API：
    你问 → 大模型 → 只回一段文字
    （它说「你应该这样改 bug」，但不真的帮你改）

Agent：
    你说「改掉这个 bug」
      → 大模型思考「我得先看看 main.py」
      → 程序真的去读 main.py
      → 大模型看到内容「问题在第 12 行，改成…」
      → 程序真的去改文件
      → 大模型「改好了，跑下测试……」
      → 程序真的跑测试
      → 大模型「测试通过，搞定」
```

这个「**思考 → 动手 → 看结果 → 再思考**」的循环，有个大名：**ReAct**（Reason + Act）。

所有的 Agent 框架、所有的项目，本质上都是在解决两件事：

1. **怎么把这个循环跑起来、跑得稳、跑得安全**（这是工程问题）
2. **怎么让循环之间记住该记的东西**（这是状态/记忆问题，也是你最疑惑的地方）

这本书就是围绕这两件事展开的。

## 0.3 为什么用 Self-Agent 当蓝本

市面上 Agent 项目很多，但大多数要么**太简单**（玩具级，看不到工程细节），要么**太专一**（只解决一类问题），要么**闭源**（Claude Code、Cursor）。

Self-Agent 是一个**企业级、全功能、开源、文档详尽**的项目，它几乎覆盖了 Agent 开发的**所有领域**：

| 领域 | Self-Agent 有什么 |
|---|---|
| Agent 内核 | LangGraph 状态图、ReAct 循环、流式、上下文压缩、任务计划 |
| LLM 层 | 多协议抽象（GLM/OpenAI/Anthropic 三套，统一接口） |
| 工具系统 | 内置工具 + MCP 远程工具 + Skill，风险分级，注册表 |
| 记忆 | 短期(SQLite/Postgres) + 长期(Store) + 画像(Neo4j) + 日志(Mongo) |
| 安全 | 工作区禁闭 + 审批闸门 + 命令沙箱（bubblewrap/Landlock）三层 |
| 协议 | MCP（接外部工具） + A2A（Agent 间协作） |
| 企业能力 | 认证(JWT)、多租户、限流、RAG、用量统计、可观测(OpenTelemetry) |
| 自我进化 | Hermes：自动学记忆 + 反思优化提示词 |
| 双形态 | 本地 CLI（零依赖 SQLite） + 服务端（四数据库） |

换句话说，**读懂这一个项目，就摸到了 Agent 开发几乎所有重要的门道。** 而且每一步都有代码、有注释、有文档、有测试，可以边读边验证。

但这本书**不只讲 Self-Agent**。每个主题都会对照「外面市面上的开源项目是怎么做的」，让你知道：

- 这个设计是普遍做法，还是这个项目特有的？
- 别人是怎么取舍的？为什么？
- 这个项目的选择是对是错，有没有更好的路？

## 0.4 这本书的写法

每章遵循一个固定套路：

1. **它是什么**（一句话白话定义，不用术语）
2. **为什么需要它**（不解决它会发生什么）
3. **怎么实现的**（贴真实代码、画图、给具体例子）
4. **关键设计决策**（为什么这么做，不这么做会怎样，附「面试常问」）
5. **外部世界怎么做**（对比开源项目，讲清楚异同）

特别地，针对你的疑惑，有一章专门讲「**状态的真相**」（[第 3 章](03-状态的真相.md)），把「状态存什么、message 什么形式、存哪、怎么存」一次性讲透。

## 0.6 一个贯穿全书的例子

这本书反复用同一个真实例子：

> **「读一下 main.py，然后加个注释」**

就这一句话。我们会跟着它走完整个 Agent：从你敲下回车，到大模型决定读文件，到审批、到改文件、到回复你。所有概念都挂在这条线上，不会东一榔头西一棒槌。

## 0.7 读之前的一个提醒

**Agent 不是魔法。** 它就是「LLM + 一个 while 循环 + 一些工具 + 一些存储」。

所有看起来复杂的东西（状态图、checkpointer、interrupt、reducer……）拆到底都是工程手段，目的是把那个 while 循环**跑得稳、跑得安全、能记住事、能中断恢复**。

只要抓住「思考↔动手的循环」这条主线，所有花哨的概念都能对号入座。这本书会一直帮你保持这条主线。
