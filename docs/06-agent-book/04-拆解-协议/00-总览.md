## 为什么需要协议（核心痛点）

### M×N 集成爆炸

没有协议之前：M 个 LLM 框架 × N 个工具 = M×N 套定制集成。

写一个工具（比如「查 GitHub issue」）要在 LangChain、OpenAI SDK、AutoGen、CrewAI……里各适配一次。换 LLM 又要重写。

### 协议的价值

定义**统一标准**，让任何一端实现一次就能和所有另一端互通：

- **MCP**：工具实现一次，所有 MCP client 都能用
- **A2A**：Agent 实现一次，所有 A2A client 都能调

像 USB-C（MCP）和 HTTP（A2A）一样——**标准化把点对点集成变成平台化**。
