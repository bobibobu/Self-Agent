# Self-Agent 启动指南

> 一页看全：四种启动形态选哪种、每种的步骤、常见问题。
> 前置条件：Python 3.12+，[uv](https://docs.astral.sh/uv/)（推荐）；Docker 与 Node.js 按形态可选。

---

## 0. 安装依赖（所有形态共用一次）

```bash
cd Self-Agent
uv sync                        # 后端依赖（含 pywebview，桌面客户端用）
npm --prefix clients/web install   # 仅首次构建 Web 前端时需要
```

LLM key：复制 `.env.example` 为 `.env`，至少填 `GLM_API_KEY`（智谱开放平台申请）。

---

## 1. 桌面客户端（推荐起步）⭐

类 ZCode/Codex 的形态：选项目目录 → 原生窗口里让 Agent 写代码、跑命令。
本地单机运行，**不需要 Docker 和任何数据库**（状态存 SQLite）。

```bash
# 方式一：双击启动（无控制台窗口，推荐）
Self-Agent 桌面版.vbs              # 仓库根目录，双击即用

# 方式二：命令行
uv run python clients/desktop/app.py
```

- 深色高级主题；任务栏/标题栏为品牌图标（⚡ 渐变闪电）
- 首次启动弹出目录选择框 → 选你的项目目录（这就是 Agent 的工作区）
- 原生窗口打开后直接对话；写文件、执行命令前会**弹审批确认**
- 空态页有 4 个建议提示词，点一下就能体验工具调用/计划面板
- 参数：`--workspace D:/proj`（跳过选择框）、`--approval auto`（跳过审批，仅沙箱用）、
  `--no-window`（只起后端不开窗口）

> ⚠️ 本地形态下会话列表/历史查询面板自动隐藏（那些数据在服务端数据库里），
> 对话上下文仍由 SQLite checkpointer 按 thread 续接；「新对话」本地生成 thread。

## 2. 服务端形态（Web + API，完整能力）

```bash
# 1) 基础设施：Postgres(pgvector) + MongoDB + Redis + Neo4j + Jaeger 一键拉起
cd infra && docker compose up -d && cd ..

# 2) 启动服务
uv run uvicorn app.main:app --reload
```

打开 http://localhost:8000/docs 看 API 文档；`clients/web/dist` 存在时
http://localhost:8000/ 直接就是 Web 聊天页（已登录态需要注册/登录，
`.env` 里 `AUTH_ENABLED=false` 可关闭认证调试）。

链路追踪：`.env` 设 `OTEL_ENABLED=true`，Jaeger UI 在 http://localhost:16686。

> **Windows 不带 `--reload` 启动时**加 `--loop app.core.eventloop:pg_loop_factory`：
> uvicorn 在 Windows 上默认 ProactorEventLoop，psycopg 异步不支持它，用户/会话表与对话历史
> 持久化会一起失效（启动日志会打 ERROR 并给出这条改法）。`--reload` 模式和桌面客户端不受影响。

## 3. Web 前端开发模式（改前端代码时用）

```bash
# 终端 1：后端
uv run uvicorn app.main:app --reload
# 终端 2：前端（vite 代理 /api → localhost:8000）
npm --prefix clients/web run dev     # → http://localhost:5173
```

改完要重新托管到后端：`npm --prefix clients/web run build`。

---

## 4. CLI（终端党，类 Claude Code）

```bash
uv pip install -e clients/cli

cd 你的项目目录
selfagent                       # 交互模式（本地内嵌 Agent，无需起服务）
selfagent "把 README 补全"       # 单次任务
selfagent --remote              # 远程模式：连接 localhost:8000 的服务端
```

本地模式状态按项目分库存放在 `~/.local/share/selfagent/projects/`。

## 常见问题

**没装 Docker / 不想起数据库能跑吗？**
能。后端会自动降级：持久化退到内存/SQLite，启动日志有 WARNING。
桌面客户端和 CLI 本地模式天生就是零依赖形态。
失去的：跨重启的会话/记忆持久化、对话历史查询、多进程共享。

**对话/检索报 429 余额不足？**
聊天模型（glm-4.5-flash）与 embedding（embedding-3）是**分开计费**的。
embedding 没余额时语义检索降级为哈希伪向量（启动日志有 WARNING），
充值后**不用重启**——`POST /admin/llm-config` 热替换 key 即可（见 llm-layer 文档）。

**换 API key 需要重启吗？**
不需要。管理员调用 `POST /admin/llm-config` 在线替换，立即生效并写回 .env。

**端口被占用？**
服务端改端口：`uvicorn app.main:app --port 8001`；桌面客户端自动挑空闲端口，
或 `--port 8899` 指定。

**GLM 回复很慢（一轮 20 秒+）？**
glm-4.5-flash 默认开思考模式，思考 token 占大头。可在
`.env` 设 `LLM_DEFAULT_PROVIDER` 换模型，或关注后续版本的思考开关配置。
