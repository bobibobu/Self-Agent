# 交付计划：真·token 流式 + Web + CLI + Hermes 自我进化

## 核心技术方案（已验证 LangGraph 1.2.10）

**真·token 级流式**的官方机制（绕过 async 的 contextvars 坑）：

```python
# agent 节点：writer 由 LangGraph 自动注入
from langgraph.types import StreamWriter
async def agent_node(state, *, writer: StreamWriter):
    async for token in llm.stream_chat(request):   # LLM 每产出一个 token
        writer({"type": "token", "text": token})   # 立即推出去，不等
    writer({"type": "tool_calls", "calls": [...]}) # 工具调用也推
    return {"messages": [ai_msg]}

# 消费端：一次调用同时拿 token 流 + 节点状态
async for chunk in graph.astream(input, stream_mode=["custom", "updates"], version="v2"):
    if chunk["type"] == "custom":   # → token / tool_calls 事件
        ...
    elif chunk["type"] == "updates": # → 节点完成/状态变化
        ...
```

## 一、后端流式重构（改 app/，这是基础）

### 改动 1：agent_node 支持 token 级流式
- 用 `stream_chat()` 替代 `chat()`，逐 token 通过 `writer` 推送
- 工具调用决策也作为事件推送（`tool_calls` 事件）

### 改动 2：tools_node 推送执行过程
- 工具开始执行 → `tool_start` 事件
- 工具结果 → `tool_result` 事件

### 改动 3：两个流式端点
| 端点 | 传输格式 | Content-Type | 用途 |
|---|---|---|---|
| `POST /chat/stream` | **SSE**（`event: token\ndata: {...}`） | `text/event-stream` | Web 前端（EventSource 原生支持） |
| `POST /chat/http-stream` | **Streamable HTTP**（NDJSON 分块） | `application/x-ndjson` | CLI/非浏览器（更轻量） |

两个端点共用同一个底层流生成器（`graph.astream` 多模式），只是输出编码不同。

### 事件类型（两种传输一致）
```json
{"type":"token","text":"你"}           // LLM 逐 token
{"type":"tool_calls","calls":[...]}    // agent 决定调工具
{"type":"tool_start","name":"get_weather"}
{"type":"tool_result","name":"...","content":"..."}
{"type":"done","thread_id":"...","reply":"完整回复"}  // 结束，附完整文本
{"type":"error","message":"..."}
```

## 二、Web 前端（clients/web/，React + Vite）

- 聊天界面 + 消息气泡 + Markdown 渲染
- **EventSource 接 SSE**，token 逐字显示（打字机效果）
- 工具调用过程实时展示（"正在调用 get_weather..." 折叠面板）
- 会话侧边栏（thread_id）、用户切换（user_id）、记忆/工具面板
- 独立目录、独立 package.json，不耦合后端源码
- 启动：`cd clients/web && npm install && npm run dev`

## 三、CLI 客户端（clients/cli/，Python）

- 交互式 REPL（`selfagent` 命令），对标 Claude Code 体验
- **httpx 接 Streamable HTTP**（NDJSON 流），逐 token 用 rich 实时渲染
- 工具调用过程实时显示（spinner + 结果）
- 命令：`/new` `/switch` `/user` `/tools` `/memory` `/profile` `/help` `/exit`
- rich 做彩色+Markdown，prompt_toolkit 做输入历史/多行
- 独立 pyproject.toml，`pip install -e .` 后全局可用
- PowerShell/CMD 均可：`selfagent` 或 `selfagent "你好"`

## 四、Hermes 自我进化（app/evolution/）

### 能力 A：自动记忆画像学习（被动）
对话后异步用轻量 LLM 抽取事实 → 写入长期记忆 + 用户画像。fire-and-forget。

### 能力 B：反思 + 提示词自优化（主动）
`POST /evolution/reflect` 触发：回顾近期对话 → 自评打分 → 优化系统提示词（存版本，可回滚）。

### 目录
```
app/evolution/
├── memory_learner.py   # 能力A
├── reflector.py        # 能力B
└── prompt_store.py     # 提示词版本管理
```
配置开关 `HERMES_LEARNING_ENABLED` / `HERMES_REFLECTION_ENABLED`，默认开。
